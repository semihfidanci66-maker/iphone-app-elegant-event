Handy-Fernbedienung:
Internet-Zugang bei jedem Programmstart automatisch öffnen
Neue Adresse als Push aufs Handy schicken (ntfy-App)
1. App „ntfy“ aufs Handy laden. 2. Dort dieses Thema abonnieren. 3. „Test senden“ drücken. Die Nachricht enthält nur die Adresse, nie den Zugangscode.

Zugangscode

Von außen fragt die Seite nach diesem Code. Wer Adresse und Code hat, kann alles steuern – gib ihn nicht weiter. Ändern geht nur hier am PC.
Tipp: Seite am Handy öffnen, dann „Teilen → Zum Home-Bildschirm“. So startet die Fernbedienung wie eine App.
